# Lab 5 Reflection

## 1. What is static code analysis?
Static code analysis examines source code without running it to identify potential bugs, security problems, and style violations.

## 2. What did the tools identify?
Pylint identified code-quality issues, Bandit identified security risks, and Flake8 identified formatting problems.

## 3. What did you learn?
I learned that hardcoded passwords, unsafe evaluation, and poor exception handling can make programs less secure and reliable.

## 4. Why is static analysis useful?
It helps developers identify problems early, improve readability, and maintain more secure and reliable code.
